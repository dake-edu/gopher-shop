# Редакционное руководство

Сохраняем стиль shanraq.org: обращение на «вы», конкретная задача, небольшой работающий пример, объяснение результата и самостоятельный шаг. Каждый новый термин объясняем при первом появлении. Английское имя API оставляем неизменным и связываем с русским смыслом.

## Ритм главы

Зачем это нужно в магазине → что уже надо знать → предскажите результат → запустите небольшой пример → разберите наблюдение → внесите изменение в магазин → намеренно сломайте и исправьте → решите самостоятельно → объясните своими словами.

В основной линии каждый листинг либо полный запускаемый файл, либо явно обозначенное изменение с точным путём и исходной контрольной точкой. Многоточия нельзя выдавать за исполняемый код. Ответы находятся после упражнений, а не перед ними. Подсказки выдаются ступенями. Обязательная задача имеет проверяемые условия; дополнительная не нужна для следующей главы.

Копирование кода дополняем предсказанием, объяснением и переносом на новые данные. Не обещаем освоить тему за фиксированное число минут и не объясняем обучение недоказанными психологическими тезисами. Аналогию завершаем указанием, где она перестаёт работать.

## Техническая редактура

Один источник для листинга и программы; перед публикацией внедрить извлечение фрагментов в текст. Проверять вывод, а не только парсинг. Для времени, случайных значений и конкурентного порядка указывать меняющиеся части. Не сочинять результаты замеров. Сохранять версию Go, ОС и команду запуска рядом с отчётом проверки.

Современные возможности включать по учебной пользе. Сначала понятная конкретная функция, затем обобщение, если оно решает повторение. Интерфейс вводить вместе с потребителем и необходимой границей. Каждый фоновый процесс должен иметь владельца, условие завершения и способ проверить отказ.

## Цифровое издание

Единый текстовый источник → PDF с выделяемым текстом, EPUB 3.3 с адаптивной вёрсткой и HTML для офлайн-чтения. Все три формата обязательны по уточнению пользователя от 2026-09-10. План основан на [EPUB 3.3](https://www.w3.org/TR/epub-33/) и [EPUB Accessibility 1.1](https://www.w3.org/TR/epub-a11y-11/). Соответствие доступности не объявлять до проверки.

Оглавление и обратные ссылки к ответам; уникальные идентификаторы глав; код текстом, не снимком; короткие строки листингов; поясняющий alt-текст; подписи таблиц и схем; информация не зависит только от цвета. Проверить экран телефона, электронную читалку, тёмную тему и печать в оттенках серого. Формальные проверки EPUBCheck и Ace дополнять ручным чтением.

Обложка: крупное название, читаемое в миниатюре, знак shanraq.org и собственная геометрическая композиция книги/окна терминала. Пока это направление, не готовый макет. Схемы процессов — векторные; графики — только по сохранённым измерениям. Не добавлять декоративные графики ради объёма.

Выпуск содержит номер редакции, дату проверки технологий, историю исправлений и описание лицензии текста и кода. Метаданные автора и издателя взять из подтверждённых исходных данных перед публикацией; ISBN не выдумывать.

## Три формата скачивания

PDF: встроенные шрифты с разрешением на распространение, закладки, кликабельное оглавление, выделяемый код, отсутствие обрезанных строк и таблиц.

EPUB: адаптивный текст, навигация, встроенные иллюстрации, читаемые листинги, проверка EPUBCheck и ручная проверка в читалках.

HTML: ZIP-архив с index.html, отдельными страницами глав, стилями, изображениями и локальным поисковым индексом. Открывается после распаковки без сервера и сети. Навигация работает без JavaScript; поиск и копирование кода имеют понятное поведение при ограничениях file://. Не использовать CDN, загрузку индекса через fetch или сервис-воркер как обязательное условие чтения. Проверить открытие из пути с пробелами и кириллицей. Для онлайн-предпросмотра можно использовать ту же сборку.

У каждого выпуска единый номер версии; в архиве выдачи — три формата, инструкция и контрольные суммы. Магазин предлагает отдельную загрузку каждого формата и всего комплекта. Форматы одной редакции дают одинаковое содержание. HTML не заменяется ссылкой на сайт: покупатель получает скачиваемую копию.

## Уточнение стиля первоисточника

В intro.md курса явно названы подходы: сначала целое, затем детали; опорная карта; бытовой образ; право вернуться и разобраться. Эти четыре приёма сохраняем как устройство материала, без обещания ускоренного обучения и без необходимости авторизоваться на сайте для чтения книги. В первых главах сначала даём результат/полную программу, затем разбираем действия. Проверка знания не превращается в оценку личности читателя.
