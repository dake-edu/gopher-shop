# Аудит самостоятельного обучения — 16 сентября 2026

Результат: рабочая редакция **0.5.1-draft**. Исправлены подтверждённые дефекты текущей рукописи, прежних учебных глав и нескольких демонстраций. Это не отметка готовности всей книги: написаны только предисловие и главы 1–9 из запланированных 42.

## Границы проверки

Прочитаны все десять файлов `book/manuscript`, исходники контрольных точек, правила проверки и издательской сборки; просмотрены программа, матрица покрытия и договор с читателем. ## Проверки и артефакты

Среда: macOS arm64, Go 1.27.1, Python 3.14.5. Go установлен для проверки отдельно; системная установка не заменялась. Издательские Python-зависимости установлены в `book/.venv`.

- `python3 book/tools/check.py`: 58 успешных команд, десять читательских глав, восемь самостоятельных исполняемых контрольных точек. Отчёт — `book/research/verification.json` (генерируется локально).
- `go test -race ./...` и `go vet ./...` корневого проекта: успешно. Корневая команда не включает вложенные модули книги — они проверены отдельно.
- Семь тестов издательской подсветки: успешно.
- `npm run docs:build`: успешно, VitePress 1.6.4. Это проверка сборки страниц, не исполнение каждого псевдокода и не проверка всех Mermaid-схем в браузере.
- PDF: 62 страницы; визуально просмотрены страницы 10, 53 и 57. Полная проверка чтения, доступности и каждой страницы не заявляется.
- EPUBCheck 5.3.0: 0 ошибок, 0 предупреждений.
- Структурная проверка: 14 HTML-страниц, 88 локальных ссылок, структура EPUB, контрольные суммы и совпадение ZIP кода с исходниками.
- SQL-схема проверена в отдельном временном PostgreSQL 16: создание таблицы и запись корректной книги прошли; отрицательная цена и NaN отклонены. Сервер остановлен, временный кластер удалён.
- Compose: конфигурация разбирается. Docker daemon локально не запущен, полный запуск через Docker не проверялся.

Артефакты находятся в `book/build/preview`: PDF, EPUB, HTML ZIP и `go-book-preview-code.zip`. Они исключены из Git; для повторной сборки команды находятся в `book/README.md`. Публикация, push и удалённый CI в этой задаче не выполнялись.

## Что остаётся до законченного учебника

Главы 10–42, полноценный каталог структур, сохранение заказов, права доступа, платежи и выдача файлов отсутствуют. Указание их в программе не заменяет объяснение, исходник и упражнение. Исправление этого пробела требует продолжения рукописи, а не объявления нынешних девяти глав полным курсом.

Старое приложение остаётся локальной демонстрацией: оно не имеет законченной аутентификации, авторизации и надёжной обработки заказов. Его модель цены `float64` сохранена ради совместимости существующих API и форм и явно отделена от новой книги. Миграция денежных данных и API должна быть отдельным согласованным изменением. Начальная SQL-схема не обновляет существующую базу.

Нельзя обещать полное отсутствие затруднений у самостоятельного читателя без наблюдения за читателями. Перед выпуском дать несколько глав начинающим людям без устных пояснений, записать места остановки, объём подсказок и результат повторной задачи. Проверить EPUB в реальных читалках, HTML с клавиатуры и без сети, PDF с учётом доступности: текущий PDF не тегирован.
