# Связь книги с репозиторием

Канонический репозиторий: https://github.com/dake-edu/gopher-shop.
Начальная ревизия при клонировании: a4d5f5029996dfbde89c2f083558918b02b4fe95.
Локальный путь: /Users/dake/Education/gopher-shop.

Каноническая рукопись теперь в book/manuscript; реестр book/book.json сопоставляет главы и независимые Go-модули. Их пути совпадают с именами модулей github.com/dake-edu/gopher-shop/book/examples/.... Проверка сравнивает реестр с файлами, выполняет код и подставляет листинги в текст. Копии исходников в публикациях не редактируются вручную.

Существующие docs/, lessons/, cmd/ и internal/ — предыдущая версия курса. Не выдавать их за уже синхронизированный финал новой книги. Переносить решения последовательно, начиная с модели денег и доменных инвариантов, после соответствующих глав и проверок. Текущий Go корневого приложения отличается от версии контрольных точек; они проверяются отдельно.

Публикации и промежуточные результаты — book/build, исключены из Git. Для завершённого выпуска зафиксировать Git tag и полный commit SHA кода; вставить их в метаданные трёх форматов. До локального коммита/публикации новых файлов не вставлять несуществующие GitHub-ссылки на главы. При локальной проверке использовать пути и SHA-256 из отчёта.

Отдельный workflow проверяет каждую контрольную точку на трёх ОС. Его наличие не равно успешному выполнению на GitHub: удалённый прогон нужно подтвердить после публикации изменений.
