# Ознакомительный фрагмент книги

«Go: от первой строки до интернет-магазина», **0.20.0-sample**. Здесь доступны предисловие и главы 1–12, а также 11 исполняемых контрольных точек глав 2–12. Полная книга содержит 42 главы; её описание и условия покупки — на [shanraq.org](https://shanraq.org/shop/go-book).

Фрагмент предназначен для бесплатного чтения перед покупкой: [PDF, EPUB, HTML и код](https://github.com/dake-edu/gopher-shop/releases). На сайте магазина его можно подключить как «Читать 12 глав бесплатно». Он завершается переходом к полной книге.

## Начать обучение

Установите Go 1.27.1 по [главе 1](manuscript/01-workspace.md). Распакуйте `go-book-preview-code.zip` из ознакомительного выпуска. Покупка и Git для работы с примерами не нужны. Откройте терминал в распакованной папке `book/examples/02-first-program`:

```sh
go run .
```

`go run` собирает и запускает программу; отличие от сохранения исполняемого файла через `go build` объясняется в [главе 2](manuscript/02-first-program.md). С главы 10 точка входа переносится в `cmd/shop`:

```sh
go run ./cmd/shop
```

Каждая глава имеет собственный `go.mod`. Работайте в копии нужной контрольной точки. Точный перечень изменений между главами включён в архив кода как `book/TRANSITIONS.md`.

## Собрать фрагмент

Из корня репозитория, с Go 1.27.1 и Python 3.12 или новее:

```sh
python3 -m venv book/.venv
book/.venv/bin/python -m pip install -r book/requirements-build.txt
python3 book/tools/check.py
book/.venv/bin/python -m unittest discover -s book/tools -p 'test_*.py'
book/.venv/bin/python book/tools/build_preview.py
book/.venv/bin/python book/tools/validate_preview.py
```

В PowerShell вместо `python3` используйте `python`, а вместо `book/.venv/bin/python` — `book/.venv/Scripts/python.exe`. Для чтения и запуска Go-примеров инструменты сборки книги не требуются.

Результат в `book/build/preview/`: PDF, EPUB, HTML ZIP, архив кода и SHA256SUMS.txt. HTML ZIP нужно распаковать и открыть `index.html`. Тот же каталог HTML подходит для размещения на сайте. Сборка проверяет, что в исходниках и архивах отсутствуют главы после 12-й; закрытый издательский репозиторий ей не нужен.

## Граница ознакомления

К главе 12 работает каталог с шаблонами. Вход, регистрация, заказы, оплата, библиотека покупателя и административная часть изучаются в полной книге. Скриншот итогового магазина в предисловии показывает цель всего проекта, а не возможности контрольной точки 12.

Примеры прежнего курса сохранены отдельно. Условия ранее опубликованных материалов не изменяются; исходный код распространяется с LICENSE в корне. Бесплатное чтение этого фрагмента не предоставляет доступ к последующим главам или полной платной сборке. Атрибуция изображений: [NOTICE](assets/brand/NOTICE.txt).

## Размещение на shanraq.org

После проверки форматов запустите `book/.venv/bin/python book/tools/prepare_sample_site.py`. Получится `book/build/preview/go-book-sample-site.zip`: страница выбора «Читать онлайн / Скачать», HTML-книга и отдельные PDF, EPUB, HTML ZIP и код ZIP. Распакуйте его в публичный каталог сайта `/static/shop/go-book-sample/0.20.0-sample/` и укажите его `index.html` в ссылке на фрагмент карточки книги. Внутренние ссылки относительные; весь фрагмент открывается без авторизации. Полные платные файлы в этот каталог не копируются.


В редакции 0.20 расширены главы 3–7: восемь небольших запускаемых опытов перед кодом магазина объясняют значения, ветвления, циклы, функции, текст и контейнеры. Их ожидаемый вывод проверяется автоматически. Это первый этап педагогической переработки; наличие всех глав не означает завершённую проверку самостоятельного обучения.
