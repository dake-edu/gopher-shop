# Источники и технологическая база

Проверено 2026-09-10.

- https://go.dev/doc/devel/release — на дату проверки указана стабильная Go 1.27.1 от 2026-09-01. Это целевая версия для будущего прогона книги.
- https://go.dev/doc/go1.27 — изменения версии; каждую используемую новую возможность проверить отдельно перед включением.
- https://go.dev/doc/database/sql-injection — параметры SQL передаются отдельно от текста запроса.
- https://docs.docker.com/reference/compose-file/services/ — restart policy; исправляет категоричное утверждение старой рукописи.
- https://www.w3.org/TR/epub-33/ — формат EPUB.
- https://www.w3.org/TR/epub-a11y-11/ — доступность EPUB.

Локальный go version: go1.26.6 darwin/arm64. Проверка на нём не доказывает совместимость с целевой Go 1.27.1. Системный Go в этой сессии не менялся. Перед написанием исполняемых глав подготовить отдельный инструментальный набор и фиксировать фактически использованную версию.
